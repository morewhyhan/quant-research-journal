# Quant Research Journal

这个仓库只记录已经值得保留的研究结论，不保存所有临时脚本、全量数据和重复回测输出。

## 目录规则

- 一个策略一个目录。
- 每个策略目录独立保存该策略的结论、源码、参数、关键回测包、试盘记录和复刻说明。
- 未形成有效结论的后续实验只做简短备注，不作为主线展开。

## 当前保留策略

| 策略目录 | 内容 |
| --- | --- |
| `strategies/E0V1E-v1/` | V1 原始/服务器实盘快照版本，包含源码、参数、live 配置、关键回测和这几天试盘结果 |
| `strategies/E0V1E-v3/` | V3 主版本和少量关键变体，包含源码、参数、关键回测包和跨样本结论 |

## 当前不纳入主线

- V3 后续 V4-V12：试过很多风控、趋势、BTC regime 等版本，但没有形成比 V1/V3 更稳定、更值得保留的主线。
- LSTM/Transformer AI 策略：目前只作为临时研究结果存在，暂不提升为主线策略目录。以后如果继续研究，再单独建策略目录。
