# E0V1E V1

## 定位

V1 是当前服务器实际运行过的主策略版本，也是目前最值得保留的主线之一。

它的特点是：

- 回测收益能力强，尤其在 2025 和 2026H1 的下跌环境里，空头贡献非常大。
- 胜率高，但单笔异常亏损会明显影响资金曲线。
- 回撤并不低，不能只看总收益。

## 当前判断

V1 可以保留继续研究，但不能直接用满仓思路理解它。

关键原因：

- 2024 全年可以赚钱，但回撤很大。
- 2025 全年和 2026H1 收益很高，主要来自空头。
- 这几天服务器试盘总体赚钱，但样本只有 23 笔，其中 1 笔 UB 多头亏损很大，说明尾部亏损仍然存在。

## 主要风险

- 单月或单笔回撤可能很大。
- 实盘滑点、资金费率、成交和交易所限制会让结果比回测差。
- 货币池变化会影响表现，不能假设历史结构长期不变。
