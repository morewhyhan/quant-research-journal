# E0V1E V3

## 定位

V3 是这轮研究里最重要的改造版本之一。它的核心价值是证明策略不是完全靠单边牛市赚钱，在部分熊市样本中也有很强收益能力。

## 当前判断

V3 值得保留，但不能把后续所有 V4-V12 都当成有效进展。

目前看：

- 原始 V3 在 2024 有较高收益，但回撤仍然偏大。
- 固定 143 个币种后，V3 在 2025H1 和 2025H2 明显失效，说明通用性不足。
- `longstake25` 版本在 2025 全年和 2026H1 很强，但 2024 表现差，存在明显市场状态依赖。
- `marketregime` 版本降低了一些极端性，但收益和稳定性都不足，不作为主线。

## 保留原因

- V3 提供了多空结合、熊市收益增强的方向。
- V3 的失败样本很有价值：它暴露了货币池、市场结构和空头依赖的问题。
- 后续优化应围绕风险和市场状态识别，而不是继续堆版本号。

## 不继续展开的内容

V4-V12 暂不作为独立策略保存。它们的共同问题是：没有形成明显优于 V1/V3 的稳定方案。
