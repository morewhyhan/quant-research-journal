## 简短结论

- V1 服务器快照收益最高，但回撤仍大。
- V3 原始版不稳定，2025H1/2025H2 都亏。
- V3 longstake25 在 2025 和 2026H1 很强，但 2024 亏损。
- V3 marketregime 没有解决问题。

## E0V1E64：B0基准与V1～V5独立优化

以“服务器当前V3 + 60/40动态仓位”为B0基准。以下编号仅属于E0V1E64研究系列，与前面的历史V1、V3名称不同。

| 编号 | 优化方向 |
| --- | --- |
| B0 | 原样基准，重新核验与历史864笔记录一致 |
| V1 | 空单最差价格方向修正及CCI亏损回升退出 |
| V2 | short_1亏损且未恢复时的4小时超时退出 |
| V3 | 趋势和波动条件决定是否投入预留资金 |
| V4 | 按入场信号调整原动态仓位 |
| V5 | 有条件延后盈利退出，限制延长时间和利润回吐 |

查看[2025全年六版本对照表](backtest-results/e0v1e64-2025/README.md)、[详细规则](backtest-results/e0v1e64-2025/SPEC.md)、[全部源码与参数](versions/e0v1e64/README.md)。
候选各自从B0派生，采用相同数据及参数口径；所有结果为本地研究回测。

| 版本 | 2025全年收益 | PF | 最大回撤 | 交易数 |
| --- | ---: | ---: | ---: | ---: |
| B0 原样基准 | +795.52% | 1.414 | 33.02% | 864 |
| V1 空单退出校正 | +966.11% | 1.338 | 31.49% | 991 |
| V2 亏损超时退出 | +1235.78% | 1.276 | 47.20% | 1134 |
| V3 预留资金条件投入 | +663.46% | 1.374 | 32.88% | 864 |
| V4 信号仓位系数 | +696.94% | 1.425 | 31.39% | 864 |
| V5 盈利持仓延长 | +1551.53% | 1.560 | 26.40% | 855 |

本轮仅V5同时提高收益和PF；其单笔EV由B0的+0.361%提高到+0.484%。
这是2025样本内候选筛选，尚未验证其他时间段，也未部署实盘。

## E0V1E64第二轮：V5冻结基准与V6～V9

**重要数据更正：** 同一2025归档有196份5m文件，但年度内实际导出币池为180；缺少2025资金费率，前后两轮E0V1E64全年数字均是“手续费已计、实际资金费未计”的旧口径，不等于完整成本后的实盘收益。7月试验因mark缺失不采用；另补跑三类数据齐全的6月1～29日。详见[数据质量核验](backtest-results/e0v1e64-r2-2025/DATA_QUALITY.md)。
