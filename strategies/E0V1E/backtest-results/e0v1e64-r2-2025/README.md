# V5第二轮优化完成：V6为研究候选，尚未替换实盘

V5已冻结原样复跑，855笔进出记录及收益、PF、回撤与上一轮全部一致。V6～V9四版相互独立；以下按用户要求优先比较收益和PF。

## 结论先看

**V6是本轮唯一在2025全年和2026年6月1～29日两组比较中，都同时超过V5收益与金额PF的候选。** 改动只有一个：在原V5允许延后盈利退出的情况下，把延长上限从60分钟改成120分钟；不是所有交易强制持有两小时，不是加杠杆，也没有改成更宽亏损止损。

全年优势小，另一段短期结果支持继续研究，但不能据此宣称已经显著、稳定地提高未来EV。V5保留，服务器策略未改动。

## V6究竟改善了什么

- 全年平均单笔收益（历史EV）从+0.4838%到+0.5072%；等额单笔PF从1.4563到1.4810。因此不仅是复利金额权重改变，交易收益序列也有小幅变化。
- 2025年839笔入场能与V5匹配：790笔退出相同，49笔退出改变。这49笔正是旧版60分钟到时退出单，平均收益由+1.7798%变成+2.0654%，其中没有原赢家变成亏损单。
- 同时新增11笔、少了16笔原入场，占仓替换也影响了全策略结果，不能把全部收益差只归功于这49笔。
- 初始8000时，全年期末余额由132122.27变为136791.86，增加4669.59，约比V5期末权益高3.53%。收益率增加58.37**个百分点**，不是“比原来多赚58%”。
- 6月29天组，单笔EV由+0.9113%到+1.1177%，等额PF由2.2644到2.7582，交易由100笔减到91笔。

## 不应忽略的代价

- 2025年一季度，V5收益+50.59%、PF1.287；V6只有+27.72%、PF1.139。不是每个市场阶段都改善。
- 全年盈利月份从11个月减至10个月；6月补充组回撤由15.32%升到16.61%。收益/PF提高并不代表波动一定更小。
- V7更紧的利润线虽让该类退出看起来更好，但全年总收益和PF下降；不要用单一退出标签的盈亏替代整个策略表现。
- V8平均亏损单变浅，但亏损次数与交易替换增加，全年PF跌到1.392、回撤52.67%；修正方向错误不保证原退出门槛本身有优势。不能为了保留漂亮回测而把这个已知错误当作正确逻辑。
- V9的855笔入场/退出与V5完全一样，等额PF和单笔EV也相同；金额PF略高主要是资金权重改变，以降低收益为代价，按本轮优先级不选它。

## 试验完整性与下一步判断

已完成15次真实普通回测：5版×2025全年、5版×7月试验、5版×6月替代组。7月因为mark缺失而**不采用为有效验证**，保留原始结果与说明，不用其数字支持V6。详见[数据质量核验](DATA_QUALITY.md)。

策略规则11项、报告计算3项测试通过；完整源代码、同名参数JSON、全部父类、原始ZIP、数据/输入哈希、逐笔变化均归档。没有修改服务器，没有删除失败版本。

当前判断：将V6保留为下一步研究候选，V7/V8/V9不替换V5。若继续追求可部署结论，优先补齐2025真实资金费、检查原有OHLC软退出/止损时点和高水位重启恢复，再用更长的独立时间段验证；不从这一轮直接推断未来月收益。
