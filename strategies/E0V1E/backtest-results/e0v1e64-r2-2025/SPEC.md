# V5第二轮优化：先定规则，再回测

本轮基准是 **E0V1E64_V5**（服务器V3 + 60/40动态仓位 + 有条件延后盈利退出），不是服务器当前原版，也不是历史仓库的V3 longstake25。V5不作任何修改；V6～V9分别从V5独立派生，互不叠加。全部为本地研究，不部署实盘。

## 提出假设的已有证据

上一轮2025全年V5：855笔，收益+1551.5284%，金额PF 1.56049，等额单笔PF 1.45633，平均单笔收益+0.48383%，最大回撤26.4016%。这些数字已经参与选定本轮方向，2025不是样本外。

- 延长60分钟到时退出49笔，平均盈利1.780%；可能有趋势被时间上限打断，但这本身并不能证明继续持有更好。
- 利润回吐退出216笔，其中29笔亏损，平均亏损单约-0.513%。该退出是5分钟回调软条件，不保证按触发线成交；不能将其误称为锁死利润。
- short_1共643笔，71笔亏损，亏损单平均-8.981%；尾部亏损仍然较重。原始空单用min_rate检查最差浮亏，方向不正确。
- short_new仅40笔，等额PF 2.069、EV +1.366%；short_1等额PF 1.451、EV +0.447%。小样本且数据内选择，只尝试温和权重，不删除币对/亏损单。

## 固定规则

| 版本 | 相对V5唯一研究方向 | 预期与可能代价 |
| --- | --- | --- |
| V5 | 冻结基准原样复跑 | 必须复现上一轮855笔及收益、PF、回撤 |
| V6 | 盈利延长期上限60分钟改为120分钟；其他不变 | 给趋势更多时间，也可能增加利润回吐、占仓和错过信号 |
| V7 | 延长期回吐线由max(0.2%, 已观察峰值利润×50%)改为max(0.2%, 峰值×70%) | 较早止盈，也可能被正常波动洗出，软退出仍有跳空风险 |
| V8 | V5包裹已验证V1空单退出：以入场后的已完成K线高价及当前报价追踪空单最差价格；最差利润≤-10%、当前利润>-5%、CCI<480时退出 | 减少恢复后再跌回止损的风险；可能提前砍掉最终回本单；多单与V5盈利延長逻辑不变 |
| V9 | V5退出不变，动态仓位乘short_1=0.90、short_new=1.10，多单=1.00；不超过原可用资金上限 | 降低弱信号风险权重；资金PF可能改善，但总收益可能减少 |

V6/V7保留v5_退出标签以便横向比较；V8修正退出仍标v1_cci_loss_cover。V8/V9的Python多继承顺序经过单元测试，不是把两个独立机器人一起运行。

V5原始条件：fastk盈利退出、方向有利且利润在[0.5%,3%)时才延长；趋势判断用5m MA120/MA240（10/20小时）和一小时前MA120斜率，不是2/4小时均线。峰值只记录当时custom_exit收到的利润，不取当前尚未完成K线的最高/最低价。

60/40含义：下一次开仓基于账户已实现高水位回撤分档使用60%、73.3333%、86.6666%、97%的总权益；不是同一亏损单追加资金，也没有外部注资。V9只再加信号权重，不改变分档门槛。

## 统一口径与事先评价标准

- 普通全年回测20250101–20260101，UTC；初始8000 USDT，5m，单持仓，手续费单边0.05%，保护机制开启，缓存禁用。
- 同一198项白名单、同一196个有5m数据币对及mark/funding文件；不缩小到赢家池。缺少SPACE、GRAM与上一轮一致。
- 同一冻结参数、离线市场补丁、资金规则和数据。每版独立进程，串行运行以避免内存耗尽。
- 先V5全量复跑，逐笔核对入场/退出时间、方向、信号、理由、单笔收益；未复现则停止比较。
- 优先同时提高全年净收益和金额PF；列出等额单笔PF、平均单笔收益EV、回撤、月度和季度切片、交易替换数量。若只提高一项，明确是取舍，不宣布全面提升。
- 不根据本轮结果再调参数；不隐藏失败版本。代码/配置/规则/数据SHA256及结果ZIP哈希留档。

## 局限

这是同一2025样本上的第二轮候选筛选，不能据此证明长期EV或未来实盘月收益。月/季度只是连续回测的已实现切片，不是独立样本外重跑。新上市币种覆盖不同，现有白名单有存续/选择偏差；原始OHLC止损模拟、滑点、资金高水位重启恢复仍未解决。策略配置虽然有leverage字段，实际杠杆以导出交易记录为准，不能仅凭字段宣称2倍。

运行：在ft_userdata项目根目录WSL执行 `.venv/bin/python validation/e0v1e64-r2/test_variants.py`，然后 `.venv/bin/python validation/e0v1e64-r2/run_suite.py --workers 1`；中断后加 `--resume`。汇总为RESULTS.md和year-2025/comparison.json。
