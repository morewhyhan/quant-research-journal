# 第四轮环境、口径与复现

- 沿用WSL Ubuntu / Python 3.12.3 / Freqtrade 2026.5.1；pandas 3.0.3、numpy 2.5.0、TA-Lib 0.6.8、ft-pandas-ta 0.3.16、ccxt 4.5.61、pyarrow 24.0.0。
- 在ft_userdata根目录执行`.venv/bin/python validation/e0v1e64-r3/test_variants.py`，随后`.venv/bin/python validation/e0v1e64-r3/run_suite.py`。运行器有排他锁，按完整结果哈希自动续跑，不并发运行回测。`test_reports.py`检查估值和筛选公式。
- 需要原工作区布局与已有行情文件；归档脚本中的ROOT是原工作区位置计算，不是一个无需行情和依赖的独立安装包。源码全部父类和每版JSON随目录归档。
- V5全年用上一轮真实ZIP复用，来源和哈希在year-2025/V5/completed.json中；不是一次新的全年回测。其余九次为新执行：V5～V13五版90天，四个新候选全年。
- 候选只包括V5、V14、V15、V16、V17，不是所有中间编号。V6～V13继续保留参考，当前基准由用户指定为V5。
- 原fix_dns.py模拟市场元数据、精度和杠杆档，不能等同历史交易所所有限制；不使用该脚本连接实盘。研究策略拒绝live模式。
- 2025资金费缺失仍保留；90天已有真实mark/funding，预审PREFLIGHT.json检查三类期间覆盖，结果必须出现非零资金费。不能凭文件数声称期间可用币数。
- 5m收盘估值使用完整成交量与开平仓费用、按时计入的历史资金费；对未平仓估计立即平仓的价值，未计滑点。逐笔终值及资金费必须与原导出核对，最终净值也必须与钱包余额对上。不是盘中tick最大回撤；缺失价格用前一个已完成收盘值，并记录估值缺口币对。
- R4新增28项规则测试；报告测试沿用4项合成审计。与未来数据有关的定点测试不等同于全策略lookahead-analysis；原V5的空单min_rate问题和重启高水位恢复仍未修复。
