# V14～V17 第四轮回测

本轮交付是四份策略源码和同名JSON参数，以及两段正式回测结果；没有部署服务器。

- 源码/规则说明：[E0V1E64_R4](../../versions/e0v1e64-r4/README.md)。
- 基准：从第三轮逐字节复制的V5和全部依赖；各新版本直接继承V5，不叠加。
- 本地环境：WSL Ubuntu、Python 3.12.3、Freqtrade 2026.5.1。
- 执行：工作区根目录下`.venv/bin/python validation/e0v1e64-r4/test_variants.py`。
- 结果：[TEST_RESULTS.json](TEST_RESULTS.json)，包含测试计数、成败、源码与测试脚本SHA256。
- 结果总表：[RESULTS.md](RESULTS.md)；完整数值：[comparison.json](comparison.json)。
- 90天逐笔匹配与浮动净值审计：[FUNDED_CASE_AUDIT.json](FUNDED_CASE_AUDIT.json)。
- 最终来源/数据/配置/净值审计：[FINAL_AUDIT.json](FINAL_AUDIT.json)。
- 测试仅用合成数据/模拟持仓和真实引擎加载、信号转换接口，不读私密配置，不连交易所，不下单。
- 2026-04-01～2026-06-30为90天完整mark/funding口径；2025全年沿用旧归档，手续费已计但实际资金费缺失。
- V5的两段基准均为上一轮已核验结果复用；V14～V17各自重新回测两段，共8次新回测。
- 年化3000%只是研究目标。本轮没有版本同时达到“期末权益提高至少10%、PF不降、引擎回撤不增、5m估值回撤不增”的事前门槛。
- 不用本次规则测试替代历史回测、lookahead-analysis、实盘回放或资金费/滑点审计。
