# E0V1E64 研究系列：B0 与 V1～V5

本系列以服务器 E0V1E_v3 + 60/40 动态仓位为唯一共同基准。
编号是本次研究序号，与本仓库旧的 V1 / V3 名称无关。
所有候选独立继承B0，不相互叠加。

| 编号 | Freqtrade类名 | 研究改动 |
| --- | --- | --- |
| B0 | E0V1E64_B0 | 原样基准 |
| V1 | E0V1E64_V1 | 空单最差价格方向修正与CCI亏损回升退出 |
| V2 | E0V1E64_V2 | short_1亏损且未恢复时的4小时超时退出 |
| V3 | E0V1E64_V3 | 趋势和波动条件决定是否投入回撤预留资金 |
| V4 | E0V1E64_V4 | short_1仓位×0.9、short_new×1.1，多单不变 |
| V5 | E0V1E64_V5 | 有利趋势下延后fastk盈利退出，最多60分钟并限制利润回吐 |

本目录全部Python文件需要放在同一个策略搜索目录；同名JSON参数文件必须保留。
E0V1E_v3.py和E0V1E_v3_equity60_reserve40.py为冻结父类，避免依赖服务器后续修改。
